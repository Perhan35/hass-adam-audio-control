# pyadamaudiocontroller

AES70/OCA protocol library for ADAM Audio A-Series studio monitors.

```
pip install pyadamaudiocontroller
```

This library handles all low-level UDP communication with the speakers and has zero dependencies beyond the Python standard library. It is used by the [ADAM Audio Control](https://github.com/Perhan35/hass-adam-audio-control) integration for Home Assistant.
